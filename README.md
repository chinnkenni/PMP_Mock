# PMP 模拟考试

PMP 模拟考试练习工具，支持随机抽题、计时、错题本、每题停留时长统计等功能。

## 功能特性

- **随机抽题** — 从题库中随机抽取指定数量的题目进行模拟考试
- **倒计时** — 每题 1.5 分钟，动态计算考试时间
- **题目导航** — 快速跳转、标记题目
- **每题停留时长** — 交卷后查看每道题的停留时间，发现薄弱知识点
- **错题本** — 自动收集错题，支持专项练习和混合练习
- **打乱答案顺序** — 随机排列选项位置，避免记住答案位置
- **键盘快捷键** — 方向键切换题目，A/B/C/D 快速选择
- **解析查看** — 交卷后逐题查看正确答案和解析
- **AI 错题复盘** — 一键复制错题与对比提问，请 AI 用游戏开发案例拆解关键差异
- **PMBOK 知识速通** — 按 PMBOK 第七版 12 个核心单元快速复习，并用现有题库验证掌握度
- **中英文定位** — 每个知识单元标注中英文版对应章节与印刷页码，便于回查原书

## 项目结构

```
pmp-exam-app/
├── build-exam.js          # 构建脚本：解析 MD → 生成 docs/index.html
├── knowledge-coach.js     # PMBOK 知识速通单元、双语定位与题库映射
├── PMP练习题库-完整版.md   # 全部题目、选项、答案与解析的单文件合集
├── questions/             # 题目源文件（Markdown）
├── docs/
│   └── index.html         # 生成的考试页面（自动生成，勿手动编辑）
└── README.md
```

## 添加新题目

1. 在 `questions/` 目录下新建 `.md` 文件，格式如下：

```markdown
# 标题

1、题目文本

A、选项A
B、选项B
C、选项C
D、选项D

# 答案与解析

# 1、答案：A

解析：解析文本
```

2. 运行构建脚本：

```bash
node build-exam.js
```

构建时会自动执行选项顺序回归检查：答题阶段可以打乱选项，查看解析时必须恢复原题顺序，确保红绿标记、答案字母和解析始终一致。如果这条规则被误改，构建会直接失败。

3. 新题目会自动被发现，并同步整合到考试页面和
   `PMP练习题库-完整版.md`。

## PMBOK 参考

知识速通以 PMBOK Guide 第七版中英文 PDF 为学习定位参考。PDF 只在本地用于核对章节与页码，不会复制到 `docs/` 或随网站发布；应用中的知识点是便于复习的概括，题库也不是 PMI 官方试题。

知识单元的掌握状态来自真实答题记录：每个单元至少完成 5 道明确分配给该单元的验证题后才会标记为“已验证”，并综合历史正确率和薄弱题比例判断是否掌握，避免综合题重复抬高多个单元的进度。

## 本地运行

```bash
node build-exam.js
npx serve docs
```

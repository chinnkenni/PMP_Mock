# 答案与解析

# 1、答案：B

解析：相关方登记册中不包含参与度评估信息。该信息记入相关方参与计划。

# 2、答案：D

解析：当干系人列表变得无法管理时，应优先考虑项目干系人，以确保有效利用精力和时间来管理他们的期望。

# 3、答案：D

解析：在进行相关方分析后，与相关方管理策略相关的某些信息可能太敏感，不宜纳入公开的文件中，需要审核相关方分析的结果。

# 4、答案：A

解析：启动大会重点在于召集客户、发起人等关键相关方对项目章程中项目的目标进行评审， 并获得批准。相关方拒绝批准计划，需要项目经理采取积极的措施在启动大会召开前解决问题。选项B、C是消极的措施，未达到启动大会的目的。选项D 准备变更请求应该是在基准获得批准之后提出的新的建议。

# 5、答案：C

解析：ABD 选项中的场景出现时，都应该开展识别相关方、规划相关方参与等管理过程。

# 6、答案：A

解析：五大过程组之间会有重叠和交叉，并不是先行后续的关系。所以，识别相关方并不是只在启动过程做才做的。“识别相关方是一个持续性的过程”。当然，越早识别出相关方对项目越有利。

# 7、答案：D

解析：项目外部相关方通常是指对项目和项目结果有影响的个人或团体，因此需要用公共关系的技能来处理与其的关系。

# 8、答案：D

解析：最好的答案是相关方，因他们的输入对于收集每个项目的经验教训是至关重要的。 术语"相关方“包括所有其他团体。

# 9、答案：A

解析：相关方在整个项目中都有影响，但是他们必须被识别出来，并且在这个项目中涉及， 以此来判断他们的需求满意度。如果不尽早努力，结果可能是昂贵的变更和或是对今后项目中的不满意情绪。

# 10、答案：A

解析：项目经理掌控着项目，但是不一定掌控着资源。往往需要从职能经理那里获取人力资源。

# 11、答案：B

解析：项目经理无法回避相关方，因为他在项目中利害攸关。项目经理可以说：“不”，但是这并不能解决根本问题。处理这些变更没有太多好的方法，唯一选择是让相关方尽早地参与到项目之中来。之所以产生变更，通常是因为在项目早期缺少输入。如果项目经理早点开始和相关方进行有效的沟通，会有很大的机会在计划过程的早期就发现这些变更，那时候对项目的影响还是比较小的。

# 12、答案：A

解析：这是规划相关方参与过程的活动之一。

# 13、答案：C

解析：对重要程度不同的相关方应该采取不同的管理策略，但不应该把相关方管理局限于少数重要相关方。

# 14、答案：D

解析：这不是一个常用的相关方分类标准。

# 15、答案：C

解析：凸显模型是根据相关方的权力（施加自己意愿的能力）、紧急程度（需要立即关注）和合法性（有权参与），对相关方进行分类。

# 16、答案：A

解析：干系人登记册记录了所有已确定的项目干系人和相关信息。干系人登记册将向 Jim 提供必要的信息。

# 17、答案：A

解析：规划相关方管理需要考虑所有的事业环境因素，其中组织文化、组织机构和政治氛围特别重要，以便制定出适合项目环境的相关方管理方案。

# 18、答案：C

解析：相关方参与计划和沟通管理计划都是项目管理计划的组成部分，相关方参与计划是为有效调动相关方参与而规定的所需管理策略。沟通管理计划是描述如何对项目沟通进行规划、 结构化和监控。两个计划并不等同，虽然会有许多交叉。

# 19、答案：B

解析：相关方满意度是评价项目成功的一项关键指标。

# 20、答案：B

解析：管理积极干系人和管理消极干系人同样重要。干系人的期望和利益会随着时间的推移而变化。为了确保项目的成功，应密切管理积极的干系人，以保持他们对项目的支持和承诺。

# 21、答案：B

解析：识别相关方不只是项目经理的事，应该鼓励相关方参与，例如，项目经理应该与现有的相关方一起识别出更多的相关方。

# 22、答案：A

解析：应对权力大利益大的相关方重点管理。

# 23、答案：A

解析：项目经理在必要时可以寻求项目发起人的帮助，项目发起人是提供资金和其他重要资源的人，是项目最重要的高层支持者。

# 24、答案：D

解析：鼓励相关方参与项目工作，是获得相关方支持的最好办法。

# 25、答案：D

解析：项目相关方之间出现冲突，项目经理需要权衡各方的利益，关注利益而非立场，找出双方共同利益，确定可能的方案解决问题。选项A和B将问题升级并未解决问题。

# 26、答案：A

解析：在不显著增加项目成本的前提下，相关方对项目的影响力在启动阶段最大。

# 27、答案：A

解析：相关方对于项目可交付成果持不同意见，这是由于在项目规划过程未让相关方尽早参与，也是识别相关方过程中相关方分析的结果存在问题。选项B，沟通需求分析是确定沟通渠道，制订详细的沟通管理计划。

# 28、答案：A

解析：管理相关方参与过程是直接与相关方打交道的过程。

# 29、答案：C

解析：监督干系人的参与是项目经理的责任。项目干系人的参与，特别是在复杂项目中的参与，应持续监控。

# 30、答案：A

解析：看上去这些都是好主意，但是让相关方回顾项目要求可以帮助发现错误和变更，因此可以被当作是最佳选项。而不是B、C选项只是让相关方收到项目信息，B、C选项相对来说，参与项目的程度弱一些。

# 31、答案：B

解析：规划相关方管理过程是基于对相关方需要、利益和影响的分析，制定合适的管理策略， 为后续的管理相关方提供依据。

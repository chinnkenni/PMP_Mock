B、告诉项目团队成员客户无法按照要求的节奏提供需求
C、当有更详细信息时，细化高层次 WBS
D、让项目团队关注当前任务

# 答案与解析

# 1、答案：A

解析：属于群体决策技术中的独裁技术

# 2、答案：D

解析：制约因素才会限制团队选择

# 3、答案：B

解析：项目范围说明书描述了项目的主要可交付成果，下一步应该面向可交付成果进行层级结构分解，主要目的是将任务分解成可管理和可配置的部分，便于进度规划和成本控制

# 4、答案：C

解析：原型法通过新原型对旧原型的迭代，不断明确客户需求，体现了渐进明细的理念。D 选项，PMI解决众多干系人冲突时，以终端客户利益至上为原则，但跟原型法不直接相关

# 5、答案：B

解析：引导式研讨会通过邀请主要的跨职能干系人一起参加会议，是快速定义跨职能需求和协调干系人差异的重要技术

# 6、答案：C

解析：没有实施工作分解结构过程。由于PMBOK指南是项目“管理”的标准，所以并未列出与管理工作不太相关的各种执行工作。PMBOK指南中所列出的执行过程都是与管理工作密切相关的执行过程，不包括纯技术性的执行过程

# 7、答案：A

解析：团队迷惑的原因是没有变更控制系统的可能性最大，项目范围变更控制系统记载于项目范围管理计划，规定了项目范围和产品范围变更所应遵循的程序

# 8、答案：D

解析：题干即为控制范围的主要工作内容

# 9、答案：A

解析：控制质量过程得到”核实的可交付成果”，再把”核实的可交付成果”交给确认范围过程验收

# 10、答案：C

解析：C属于假设条件。D选项，合同条款一经确定，就成了制约因素

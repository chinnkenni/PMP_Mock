# 答案与解析

# 1、答案：A

解析：利用三点估算的方法计算最悲观成本。

# 2、答案：B

解析：不但要知道花了多少钱，还要知道花了这些钱做了多少事以及做这些事本应花多少钱。

# 3、答案：A

解析：CPI=1.04， BAC=200,000，则按照典型偏差预测的方法 EAC=BAC/CPI。

# 4、答案：A

解析：估算活动资源是项目时间管理的过程。

# 5、答案：C

解析：术语题，挣值 EV 反映的是已完工作的计划价值。注意 PV, AC的术语概念，这是挣值管理的基础信息来源。

# 6、答案：C

解析：当挣值等于完工预算时，说明项目的总计划价值已被完全挣回，项目已经完工。

# 7、答案：A

解析：CPI=0.94，挣值测量的是已完工作的成本绩效状况，是针对已完工作量化成本偏差的工具，并不能单独做预测以反映未来的成本状况。

# 8、答案：D

解析：三个月后项目已完成，那么此时 EV=PV=BAC

# 9、答案：D

解析：做决策时需要考虑机会成本，但机会成本不是实际会发生的成本，不应计入活动成本估算中。

# 10、答案：B

解析：注意题目，是多生产10个部件，那么已花费的$2500固定成本不需再包括在内

# 11、答案：A

解析：成本管理计划的内容之一是绩效测量规则，其中最重要的又是挣值管理规则，包括： 控制账户、计算挣值的方法、计算挣值的时间、进行预测的方法等。

# 12、答案：D

解析：偏差值属于工作绩效信息。

# 13、答案：A

解析：在项目开始时，较大的百分比差异是可以接受的。然而，随着更多工作的完成，可接受差异的百分比范围将趋于减小

# 14、答案：C

解析：见本章成本的种类描述部分

# 15、答案：D

解析：间接成本是不能直接计入某个项目，需要在多个项目之间分摊的成本典型的间接成本是项目执行组织的总部管理费。

# 16、答案：C

解析：明显的参数估算的特点。

# 17、答案：B

解析：项目的粗略量级估算（Rough Order of Magnitude, ROM），其区间为 -25% 到 +759； 之后，随着信息越来越详细，确定性估算的区间可缩小至 -5%到+10%。

# 18、答案：D

解析：相对来说管理储备可能性最低。

# 19、答案：A

解析：SV 小于零，说明比计划完成的工作要少。

# 20、答案：C

解析：成本基准是制定预算过程的输出之一。

# 21、答案：A

解析：虽然所有选项都将导致估算困难，但不充足的范围定义使得估算无法进行。

# 22、答案：B

解析：这就是机会成本的解释。

# 23、答案：C

解析：项目1的进度绩效指数SPI<1，成本绩效指数CPI<1，表示进度滞后，费用超支：项目2的SPI>1,CPI>1，表示进度提前，费用节省。

# 24、答案：A

解析：这是在制定预算过程中要考虑的两个储备。

# 25、答案：B

解析：成本管理过程及其相关工具和技术记录在成本管理计划中。这些参数包括精度水平（四舍五入程度）、计量单位（工作人员小时、周等）和控制阈值（与基线计划的偏差百分比）。

# 26、答案：D

解析：项目总资金需求就是项目预算，包含了管理储备。

# 27、答案：B

解析：根据项目进度管理计划，将费用按照其拟定发生的目历期限汇总。

# 28、答案：D

解析：控制成本定义。

# 29、答案：A

解析：由于 CPI=挣值/实际成本，这意味着实际成本=挣值/CPI=100000 美元/0.8=125000 美元。这意味着团队在项目上的花费比计划的要多。

# 30、答案：A

解析：成本预算中可包括管理储备，成本基准中肯定不包括管理储备。成本预算大于或等于成本基准

# 31、答案：B

解析：挣值的定义。已完成工作的计划价值。

# 32、答案：B

解析：成本基准是经过批准的、按时间段计列的累计成本计划，可用S曲线表示。

# 33、答案：C

解析：类比成本估算通常被认为不如其他估算方法准确。

# 34、答案：B

解析：更细致的预算便于更细致的控制。

# 35、答案：B

解析：管理储备金不是项目成本基线的一部分，但将包含在项目的总预算中。

# 36、答案：B

解析：S曲线横轴反映的是项目的进度计划，纵轴反映的是成本的数值，当使用应急储备， 说明项目的实际成本增加，则S曲线应该向纵轴的上方偏移。

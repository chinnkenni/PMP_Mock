50、在一个工程项目中，项目经理应用了在之前更为复杂项目中成功应用的项目管理方法，项目团队成员抱怨说这类项目的每份文件同行评审需要花费太多的精力。若要确保质量成本满足项目特征，项目经理应该怎么做？

A、省略同行评审
B、查询质量测量指标
C、执行质量审计
D、在计划中考虑质量成本

# 答案与解析

# 1、答案：B

解析：应该质量规划阶段确定统计抽样的频率、样本数和统计分析方法。参考控制质量工具， 统计抽样的描述。

# 2、答案：A

解析：质量成本是指为防止不符合要求、评估产品或服务是否符合要求以及未能满足要求（返工）而进行的投资所产生的总成本。

# 3、答案：B

解析：最好是在设计时考虑可交付成果的质量，而不是在检查时发现质量问题。预防错误的成本通常远低于在检查或使用中发现并纠正错误的成本。

# 4、答案：A

解析：返工多意味着质量管理差，应该在项目质量管理过程进行评审，好处是减少因返工而造成的成本超支和进度延误。

# 5、答案：A

解析：分析根本原因并找出各种因素如何与潜在问题或结果相联系，需要使用因果图的工具和技术。

# 6、答案：D

解析：为了提供最佳结果，质量审计应该是一个由独立实体执行的结构化过程。

# 7、答案：C

解析：控制质量过程确认为能满足干系人的需求的可交付成果，才能交给确认范围过程正式验收。

# 8、答案：C

解析：答案C，只有符合核对单中相关质量测量指标才能被接受。

# 9、答案：D

解析：这种类型的测试被称为破坏性测试，它被归类为评估成本。与其他测试和检查一起， 它有助于评估产品的质量。

# 10、答案：A

解析：属性抽样是定性判断，即判断合格与否。

# 11、答案：A

解析：质量管理计划描述如何实施适用的政策、程序和指南以实现质量目标。

# 12、答案：A

解析：控制图除了具有控制上下限，其横轴反映的过程质量随时间的变化，也可以用于结果是否稳定或者达到了预期的质量。

# 13、答案：D

解析：D选项是控制质量的主要作用。

# 14、答案：A

解析：统计抽样是随机选择的过程以及工作产品的检查。

# 15、答案：A

解析：范围基准（包括范围说明书）是质量规划的依据

# 16、答案：C

解析：这是鱼骨图的一个例子。鱼骨图，也称为因果图或石川图，是一种可视化工具，用于对问题的潜在原因进行分类，以确定其根本原因。

# 17、答案：D

解析：通过质量审计工具可以确认已批准的变更请求，包括纠正措施、缺陷补救和预防措施的实施情况。同时需要注意，质量控制过程对所有已批准的变更请求进行审查，以核实它们是否已按批准的方式得到实施。

# 18、答案：A

解析：技术性能分析用于比较计划和实际的技术成果、时间表和其他性能标准。

# 19、答案：B

解析：用作标杆对照的项目可以来自任何行业或组织，只要在特定方面与本项目有可比性即可。

# 20、答案：D

解析：可以从产品质量测量结果所处的位置判断产品质量是否合格。

# 21、答案：C

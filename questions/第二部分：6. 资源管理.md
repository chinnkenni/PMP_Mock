# 答案与解析

# 1、答案：D

解析：事情被推迟决定，这是撤退的例子，参见本章解决冲突的五种方法撤退。

# 2、答案：B

解析：召开会议一定要有会议议程。

# 3、答案：B

解析：项目章程授权项目经理在项目活动中动用组织的资源，只有有了项目章程，项目经理说话才有高层的支持，更有分量。

# 4、答案：B

解析：考察团队建设的五阶段模型，即形成-震荡-规范-成熟-解散（终止）阶段。团队开始调整习惯一起工作，这是处在团队建设的规范阶段，但是由于不信任，团队建设可能会有冲突发生，导致团队建设退回到震荡阶段。

# 5、答案：A

解析：团队不能提供可交付成果，项目经理应该首先寻找最有可能解决问题的备选方案，符合积极主动的原则。选项B是在提出变更方案并获得批准后通知相关方。

# 6、答案：D

解析：了解冲突的根本原因，寻找解决方案，将冲突作为问题来解决，是采用合作和面对的冲突解决策略。

# 7、答案：C

解析：管理团队过程在项目过程中跟踪团队成员的表现、提供反馈、解决问题并管理变更， 也可以提交变更请求，更新人力资源计划，解决问题。

# 8、答案：D

解析：妥协需要寻找能在一定程度上让各方满意的方案，以便暂时或部分解决冲突。这将是处理当前局势的最佳方式，因时区差异不受任何人的控制。

# 9、答案：C

解析：Y理论、期望理论和赫兹伯格的激励因素理论都是对追求较高层次需求的人们可以产生激励作用的理论，与高科技环境下项目团队成员的高学历，高素质相对应。

# 10、答案：D

解析：开放式沟通有利于建立信任。

# 11、答案：A

解析：最好的方式是私下的直接的沟通。

# 12、答案：C

解析：应该理解并利用政治和文化氛围，来促进项目成功。

# 13、答案：D

解析：在团队建设的成熟阶段，团队成员之间相互依靠，平稳高效地解决问题。形成、震荡、 规范阶段都会存在潜在冲突。

# 14、答案：D

# 答案与解析

# 1、答案：D

解析：这种情况描述了”比较”的需要。一份趋势报告显示了随着时间的表现，一份预测报告仅仅看到了未来。一份状态报告大致是静态的（描述了某一个时刻）。比较项目结果的唯一选择就是差异分析。

# 2、答案：B

解析：项目往往有众多相关方，而项目经理的时间有限，项目资源也有限，所以项目沟通只能针对那些有利于项目成功或不沟通会导致项目失败的信息。

# 3、答案：D

解析：类似项目重复发生同样的问题，可以通过记录并沟通经验教训来避免。问题原因不明确，无法判断其他选项的有效性。

# 4、答案：B

解析：问题日志用于记录和监督问题的解决情况，并为问题解决方案中的每项行动指定责任 ^，并设定解决问题的目标日期。项目经理和项目团队都可以是问题日志中问题及解决方案灼所有者。

# 5、答案：B

解析：应该采取适当保护措施，并选择最合适的沟通技术。

# 6、答案：A

解析：相关方信息复杂属于干系人的信息需求不确定，需要审查沟通管理计划中的相关方沟通需求，如需修改可以提出关于沟通管理计划的变更。

# 7、答案：B

解析：以对方熟悉或喜欢的方式沟通，更有助干沟通效果。

# 8、答案：A

解析：团队成员关于他们工作的报告最好是在会议之外完成。会议的主要目的是交换项目信息。

# 9、答案：C

解析：见 PMBOK管理沟通定义。

# 10、答案：B

解析：虽然成本总是任何项目的一个考虑因素决定，只考虑最便宜的技术可能会损害项目。

# 11、答案：A

解析：如何管理相关方信息需求和沟通属于沟通管理计划的内容。

# 12、答案：B

解析：沟通模型包括信息发送者、接受者以及信息编码、解码和反馈，并规定了发送者和接受者的职责，是规划沟通的重要工具。

# 13、答案：B

解析：沟通需求分析的主要目的就是要确定相关方对信息的需求，例如，他们需求什么信息、 喜欢这些信息以什么方式和格式传递、为什么需要这些信息等等。

# 14、答案：B

解析：沟通计划的定义。

# 15、答案：B

解析：作为沟通规划的一部分，干系人的沟通需求被收集并记录在沟通管理计划中。这是项目管理计划的一部分。

# 16、答案：D

解析：如果是12个团队成员和项目经理沟通，则沟通渠道就是13X（13-1）-2=78

# 17、答案：A

解析：沟通管理计划还包括项目状态会议、项目团队会议、网络会议和电子邮件等各方面的指导原则。

# 18、答案：C

解析：根据 PMBOK指南，所有电子邮件通信都是非正式的。尽管这是两名官员之间的通信，但除非信息得到正式传递，否则不能被视为正式通信。

# 19、答案：D

解析：变更请求状态更新在变更日志中完成，而变更日志是实施整体变更控制过程的输出。

# 20、答案：C

解析：发送方负责信息内容清晰明确、不模棱两可和完整无缺，以便让接收方能正确接收， 并确认理解无误；接收方的责任是保证信息接收完整无缺，信息理解正确无误。

# 21、答案：B

解析：项目状态报告的定义。

# 22、答案：A

# 答案与解析

# 1、答案：A

解析：风险在项目的整个周期中是变化的。在概念和计划阶段，项目风险最多而影响最小。

# 2、答案：B

解析：蒙特卡洛分析的典型输出是累积概率分布，表示实现任何特定结果或更低结果的概率。

# 3、答案：D

解析：没有质量基准这个项目文件或项目计划。

# 4、答案：A

解析：风险临界值反映了组织与项目相关方的风险偏好程度，是项目目标的可接受的变异程度。可接受的临界风险形成了项目小组衡量风险应对计划执行有效性的比较目标。

# 5、答案：C

解析：项目经理对现有风险进行再评估以及删去已过时的风险是采用的风险再评估的工具， 而项目风险管理应该是定期状态审查会中的一项议程。D选项应急储备主要是比较剩余储备和剩余风险的匹配关系。

# 6、答案：B

解析：风险清单应该是识别风险过程所得到的风险登记册中的内容。

# 7、答案：B

解析：只有 B 中的内容都是风险管理过程。

# 8、答案：A

解析：头脑风暴就是引发大家共同的创意，会议参加者畅所欲言，目的是为了获得一份完整的风险清单。C选项，问卷调查通常在德尔菲技术中采用。

# 9、答案：B

解析：油价的不确定性是一种项目风险，它可以对项目产生积极或消极的影响。其余选项不正确。

# 10、答案：D

解析：风险审计检查并记录风险应对措施在处理已识别风险及其根源方面的有效性，以及风险管理过程的有效性，是监督风险的重要工具。

# 11、答案：A

解析：定性风险分析本来就是比较主观的分析，不太可靠：如果其所依据的数据质量很差， 就会使分析结果毫无用途。

# 12、答案：B

解析：项目经理实施应急计划或权变措施会导致变更请求，在获得CCB 批准后方可执行。 选项A和C应该是在变更被批准之后的工作。

# 13、答案：C

解析：监控风险观察清单的风险。

# 14、答案：B

解析：购买保险、履约保函、保证书和担保书都是转移风险的例子。

# 15、答案：C

解析：转移风险是风险应对策略。

# 16、答案：C

解析：已识别风险对项目整体目标的影响进行量化分析，这是实施定量风险分析过程的活动， 也是在不确定情况下进行决策的一种量化方法。

# 17、答案：A

解析：当风险无法在项目中处理或管理时，建议接受它们。在这种情况下，你的团队无法制定合适的响应策略。因此，接受风险是正确的就业策略。

# 18、答案：A

解析：建立应急储备是风险接受中的主动接受策略。

# 19、答案：C

解析：威胁的应对策略是上报、规避、转移、减轻、接受。

# 20、答案：D

解析：预期货币价值分析借助决策树来实现。

# 21、答案：D

解析：项目经理对项目的风险管理负责，而选项B，项目发起人开展风险管理活动提供资金，选项C，项目团队成员负责实施具体的项目管理活，风险应对责任人负责实施已获同意和资金支持的风险应对措施。

# 22、答案：A

解析：开展假设条件和制约因素分析，来探索假设条件和制约因素的有效性，确定其中些会引发项目风险。从假设条件的不准确、不稳定、不一致或不完整，可以识别出威胁。

# 23、答案：A

解析：参见风险数据质量评估。风险数据质量分析就是评估有关风险的数据对风险管理的有用程度的一种技术。它考察人们对风险的理解程度，以及考察风险数据的准确性、质量、可靠性和完整性。

# 24、答案：D

解析：访谈可用于针对单个项目风险和其他不确定性来源，生成定量风险分析的输入。

# 25、答案：D

解析：保险费并不是评估项目风险的因素。当你决定你会使用此种风险应对策略时才开始起作用

# 26、答案：B

解析：敏感性分析的定义。

# 27、答案：B

解析：风险是在识别风险过程中识别出来的。自然而然地，新出现的风险是在监督风险的过程中识别出来的。

D、要求供应商停止所有交付，直到问题得到解决

# 答案与解析

# 1、答案：C

解析：建议邀请书用于以技术方案为主要评价标准的采购。

# 2、答案：B

解析：控制采购的输出工作效信息。工作绩效信息中包括合同的履约情况，可以从中发现当前问题或潜在问题，可以用于支持后续索赔。

# 3、答案：C

解析：双方一旦签订合同，则必须同意任何变更，除非合同内的一些条款因为不合法而使合同无效、失效。合法性是合同基本组成要素。

# 4、答案：B

解析：正式验收和拒绝是由授权的采购管理人员来通知的。

# 5、答案：C

解析：只有工作范围非常清楚的采购，才能用固定总价合同。

# 6、答案：A

解析：需求或者范围定义明确的采购，最好采用固定总价合同，对于买方的风险最小，能够最大限度地刺激卖方在最低的成本最快的时间完成合同。选项B，工料合同适用于不能很快编写出准确工作说明书的情况。选项C，成本补偿合同用于工作范围在开始时无法准确定义时。

# 7、答案：D

解析：项目中每次采购的终止条款和替代争端解决机制都记录在相应的采购协议中。

# 8、答案：B

解析：按卖方为完成合同要求而实际发生的费用付款。

# 9、答案：B

解析：深析：改变固定费合同的唯一方法是商谈合同变更，通常以变更令的形式出现。

# 10、答案：C

解析：投标人大会的目的是让投标人充分了解采购内容，并将对问题的回答编入采购文件。

# 11、答案：B

解析：B选项是成本补偿合同。

# 12、答案：B

解析：题目问合同授予文件，合同也可称作协议、一致意见、分包合同或订购单。选项C， 采购管理计划用于指导如何管理从编制采购文件直到合同收尾的各个采购过程。

# 13、答案：D

解析：采购审计旨在对规划、实施和控制采购过程进行结构化审查，来总结经验教训，以改进将来的采购工作。

# 14、答案：A

解析：实施采购是获取卖方应答、选择卖方并授予合同的过程。选项C是管理采购活动。 选项D是规划采购过程的活动。

# 15、答案：C

解析：卖方建议书是由潜在卖方根据采购文件编写并提交的，是实施采购的输入之一。

# 16、答案：B

解析：检查是指对承包商正在执行的工作进行结构化审查，可能涉及对可交付成果的简单审查，或对工作本身的实地审查。

# 17、答案：B

解析：供方选择标准通常是采购文件的一部分。

# 18、答案：C
